One new candidate architecture is selected for future isolated implementation: a same-layout Q4 output-tile/M-resident kernel with bounded four-partition ordered FP32 partials and a deterministic FP32 finalizer in the existing `gptq_kernel.cu` path. It targets repeated Q4/qzero/scale/g_idx reads/decode, K-split FP16 atomic merge, and the NCU long-scoreboard signature; it is **not** a G017 re-label or Marlin route, and no code is written here. Guaranteed saving today: **0ms**. Strict upper envelope is bounded by owners (b4 18.536ms instrumentation-bound category; b1/b2 16.473/16.755ms Eager-only, not convertible to Graph wall).
