## INFERRED

- A MambaRadixCache class exists and appears to retain both KV references and one Mamba slot per valid checkpoint, so this is not merely a KV-only cache path.
- Deferred COW on the forward stream is intended to prevent read/write races and to give branches independent state; no measured/tested proof has yet been established for this Falcon build/config.
- Comparison consistency: hit and force-miss serial artifacts use identical prompt SHA256 per branch and same c57 runtime SHA/config; hit later branches report 768 `cached_tokens` and `cached_tokens_details.device=768`, force-miss reports 0. In the cache-hit run, repeating each branch is deterministic; hit output differs from force-miss from token 0 (branch 0) / token 1 (branch 1). No saved tensors/logits were captured at the boundary.
- `extra_buffer` is the only observed configuration that leaves the overlap option enabled while retaining radix cache; live actual overlap/throughput behavior is not yet established.
